# Architectural Decisions

- **ADR-001: Monolithic Architecture with Spring Boot 3 & Thymeleaf**:
  Chosen per specification to ensure tightly integrated authentication, server-rendered views with Spring Security dialect, and responsive UI.
- **ADR-002: Dual Interaction Kanban**:
  Support both client-side drag-and-drop with async REST API updates and accessible button fallback.
- **ADR-003: Multi-Profile Database Support**:
  H2 file/in-memory enabled by default for zero-setup execution, with MySQL configuration profile available.
- **ADR-004: Design System - Playful Geometric**:
  Memphis modern style with warm cream `#FFFDF5`, hard pop shadows, 2px borders, Google Fonts Outfit & Plus Jakarta Sans, rounded pill candy buttons, and sticker cards.
